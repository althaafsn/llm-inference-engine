# Portfolio materials

This folder turns the LLM engine work into application and interview material.

- [Case study](case-study.md) — problem, design, optimization, AWS results, failure analysis, and limits.
- [Resume entry](resume-entry.md) — primary bullets, tailoring notes, evidence map, and a defensibility checklist.
- [Learning path](learning-path.md) — eight sessions from running the system to defending the ALB result.
- [Demo script](demo-script.md) — a five-minute local demonstration.

Read the case study first. Use the learning path before you put the project on a resume. Do not claim production readiness, multi-AZ, TLS, streaming, or global admission; the measured limits are part of the story.
